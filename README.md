# EngineerHub 🚀

**EngineerHub** is a native Android application built using Kotlin and Jetpack Compose. Designed as an all-in-one productivity and calculation suite for engineering students and professionals, it provides discipline-specific engineering hubs, offline utilities, and a persistent event dashboard.

---

## 🎯 Goal

EngineerHub is designed to put the tools engineering students use most often
in one place — from engineering calculators and unit conversions to study
timers, constants, and academic event tracking.

The goal is simple: **fast, practical, and reliable engineering tools without
having to search for a different application for every task.**
## ✨ Features

### 📅 Dashboard & Event Tracker
- **Smart Event Partitioning:** Automatically categorizes tasks into **Upcoming** and **Past Events** based on parsing algorithms.
- **Local Persistence:** Powered by **Room Database (SQLite)** to ensure events persist across app launches.

### 🛠️ Multi-Disciplinary Engineering Hubs
Dedicated calculators and quick-reference tools across major disciplines:
- ⚡ **Electrical Hub**
- 📡 **Telecom Hub**
- ⚙️ **Mechanical Hub**
- 🧪 **Chemical Hub**
- 🌡️ **Thermodynamics Hub**
- 🏗️ **Civil Hub**
- 🏭 **Industrial Hub**
- 🚀 **Aerospace Hub**

### 🧰 Utility Suite
- **Unit Converter:** Fast unit conversions across length, mass, power, and memory metrics.
- **Constants Sheet:** Instant reference for essential physical and mathematical constants.
- **Pomodoro Focus Timer:** Integrated study/work timer designed for deep work sessions.

---

## 🛠️ Tech Stack & Architecture

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
- **Architecture:** MVVM (Model-View-ViewModel)
- **Local Storage:** [Room Persistence Library](https://developer.android.com/training/data-storage/room)
- **Asynchronous Execution:** Kotlin Coroutines & `StateFlow`
- **Navigation:** Navigation Compose with Modal Navigation Drawer
- **Annotation Processing:** KSP (Kotlin Symbol Processing)
